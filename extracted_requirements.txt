Scop &amp; Decizii Cheie
Platformă e-commerce de tipărire foto 100% online, în limba română. Clienții uploadează fotografii, aleg format (10×15 / 13×18 / 15×21 cm) și finisaj (Lucios / Mat), plătesc online și primesc comenzile prin Sameday Easybox sau livrare la ușă.
Auth: Email+Parolă + Google OAuth + Guest Checkout  ·  Plăți: Stripe + EuPlatesc  ·  Livrare: Easybox (auto API) + curier (manual fallback)  ·  Email: Confirmare / Expediat / Livrat / Bun venit  ·  DB: PostgreSQL

[BACKEND — ASP.NET Core]  US-102 — Register — Backend
As a
system
I want to
persist new accounts securely and trigger email confirmation
AC
• POST /api/auth/register — FluentValidation on all fields
• Password hashed with ASP.NET Identity (PBKDF2-SHA256, 10 000 iterations)
• User record: Id (UUID), Email (unique index), PasswordHash, FirstName, LastName, Phone, Role=Customer, IsEmailConfirmed=false, CreatedAt
• Generates email token (UUID), stores SHA-256 hash with 24h expiry in EmailConfirmationTokens table
• Fires IEmailService.SendConfirmationEmailAsync (async, non-blocking); logs failure but does not fail request
• Returns 201 {userId}; 409 on duplicate email; rate-limited 5 req/IP/hour

[BACKEND — ASP.NET Core]  US-105 — Login — JWT + Refresh Token
As a
system
I want to
authenticate users and issue short-lived JWT with rotating refresh tokens
AC
• POST /api/auth/login → {accessToken, expiresIn}; sets refreshToken in HttpOnly Secure SameSite=Strict cookie
• Access token: JWT RS256, 15-min expiry; claims: sub (userId), email, role, firstName
• Refresh token: opaque UUID, SHA-256 hashed in DB, 30-day expiry; rotated on every use (old token revoked immediately)
• POST /api/auth/refresh — reads cookie, validates, issues new pair
• POST /api/auth/logout — revokes refresh token in DB, clears cookie
• 5 consecutive failures → account locked 15 min; 423 response + lockout email sent

As a
system

AC

[BACKEND — ASP.NET Core]  US-306 — Payment — EuPlatesc Backend

AC

• EuPlatesc IPN endpoint: POST /api/webhooks/euplatesc — validates HMAC signature using EuPlatesc merchant key
• On success IPN: Order status=Paid; fires OrderConfirmedEmail
• On failure IPN: Order status=PaymentFailed
• Stores EuPlatescTransactionId on order for reconciliation
• IPN endpoint is public (no JWT); protected by HMAC validation only
